Assessment scope

Designed around the real engineering constraints.

The task calls for a scalable, fault-tolerant pipeline and explicitly warns that every record must trace back to a legitimate source URL. This project keeps source provenance as a first-class field.

01

Bulk acquisition

Async collectors and stateless adapters are designed to scale horizontally toward 500k+ records.

02

Fresh signals

News and jobs are filtered using normalized timestamps and a strict 24-hour freshness window.

03

LLM resilience

Provider fallback, bounded chunks, exponential backoff and jitter reduce extraction failures.

04

Entity resolution

Normalized names and a canonical seed map turn variants such as “Open AI” into one entity.

05

Source fidelity

Records retain source metadata and collection timestamps. The repository avoids fabricated submission rows and expects production runs to consume configured legitimate sources.

06

Production thinking

Clear module boundaries make collectors, extraction, resolution and storage independently scalable.
